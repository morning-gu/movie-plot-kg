# Phase 3 重建与评估报告:v0.4.1 台词增强的下游收益(2026-10-21)

数据:阈值 0.6 + 全部阶段 1 规则 + token 零交集下限的转换数据
(kept% 53/76/25),三片图谱全量重建(RD 37/37、Hackers 140/140、
Rock 466/467——1 个场景反复失败,覆盖 99.8%)。

| 影片 | 角色 F1 旧→新 | recall | precision |
|---|---|---|---|

CAUSES 1721→1824。

## 问答端:绝对持平,结构增益三倍放大

| 模式 | accuracy 旧→新 | hit_rate 旧→新 |
|---|---|---|
| full(向量+图) | 0.5167 → **0.5167**(持平) | 0.5861 → 0.5167 |
| vector-only | 0.4667 → 0.3667(-10pp) | 0.4944 → 0.4222 |
| **图增强差值** | **+5.0pp → +15.0pp** | +9.2pp → +9.4pp |

分意图(full 新):factual 0.75 / causal 0.42 / relational 0.58 /
temporal 0.33 / synthesis 0.50——temporal +2 题、synthesis +1 题、
relational -2 题、causal -1 题,净持平。

**解读**:更丰富的图(事件/角色/因果链更密)让图遍历路径的相对价值
大增(命题 2 的信号从 +5pp 强化到 +15pp);但绝对 accuracy 没涨——
因为 vector-only 地板随图变大而稀释(top-5 在 2956 节点池里竞争更烈),
天花板被检索容量卡住。**下一步杠杆在检索(top_k 扩容 / 按类型配额),
不在对齐。**

## 过程记录(修复的两个新问题)

1. **B2 别名归并截断**:meta.cast 并入后角色 65 人,单次输出 JSON
   超 max_tokens(Hackers 实证 949 行截断)→ 分批调用修复(25/批,
   按名排序聚类变体,00f2e38)
2. **QA gold 语义漂移**:事件 ID 是位置型(evt_影片_场景_序号),
   重建后位置移位——30/60 题的 gold 锚点失准(11 个 ID 缺失 +
   19 个 ID 存活但语义错位;首轮校验只查存在性,漏了语义层)。
   已逐题按主题重锚(b7a53e0)。经验:**评估集锚点在图谱重建后
   必须做语义校验,不能只验 ID 存在。**
