## 已知延后项(阶段 2 输入)

1. **短 cue 歧义是降阈值的头号风险源**:翻转几乎全部发生在 ≤5 词 cue;
   阈值降到 0.5/0.45 会放大此类错绑(评审 B1 的级联机制)
2. **逐字前缀短 cue 的规则夹缝**(Hackers cue[723] "I'm sorry." 实证):
   3 去重词 cue 不够覆盖兜底的 4 词门槛,而 containment 分支按
   短/长计分(0.53)反而低于错拼版本走 difflib 的 0.615——候选修复:
   containment 分支取 max(短/长, difflib) 或 cov 门槛 4→3(配连续段守卫)
3. **Rock 天花板在剧本对齐漂移**:1199/1763 未匹配,其 cue 最优分聚在
   0.45-0.55 带,阈值不动则 25% 已近上限
4. base 路径的 token 交集下限(拒纯字符相似命中)尚未实现(阶段 2 计划项)
5. 单阈值 0.6 下抽样 CSV 每片仅 ~20 行(仅 ≥0.6 带非空,per_band=100//5);
   阶段 2 多阈值运行自然变多,若单阈值需 ~100 条需改 sample_n 语义为每带下限
